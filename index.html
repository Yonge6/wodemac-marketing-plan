01Elian的时间怎么花

  • 两成时间陪伙伴成交：帮伙伴给学员、已有付费客户或企业客户做演示，回答技术问题，盯交付。
  • 少做的事：不自己追散客，不自己拍大量内容。内容只做给伙伴转发用的案例。

02三类客户

  1. 1. 有学员或付费客户的渠道伙伴

    同时招募 AI 培训大V、账号与充值服务商、出海服务商。优先找手上已有付费客户、能持续介绍真实需求的人。

    AI 培训大V：先帮老师把 Claude Code 的环境配好、把任务跑通，再用可复现的案例向学员和企业客户介绍。

    账号与充值服务商：从做 ChatGPT、Claude 账号开通、订阅充值及 VPN 服务的人中找。他们已有愿意为工具与使用环境付费的客户，可以进一步介绍美国独享 Mac mini、Claude Code 工作流及一站式配套服务。

    推广伙伴用专属链接带客户，按客户首单拿提成：年付 15%、半年付 10%、季付 7.5%、月付 5%。经销商的合作方式和价格单独沟通。

  2. 2. 想出海的中小企业

    按团队实际需求配置独享 Mac，把 Claude Code 接进产品开发、资料整理、出海销售和运营流程。先验证一个任务的效果，再扩大到更多成员。

    去哪找：大V的企业学员、账号与充值服务商的企业客户、出海服务商、跨境电商社群。

  3. 3. 重视省心交付的一站式客户

    从海外账号与支付、Claude 注册与订阅，到美国独享 Mac mini、远程环境和 Claude Code 工作流，按需求衔接配置与交付，让客户少花时间处理使用环境。

    重点拓展学生家长：优先覆盖北京、上海、广州、深圳、武汉等重点城市，推广“账号开通＋充值订阅＋美国 Mac mini 远程使用”的组合服务。

    余老师负责 ID 注册、账号开通、订阅和支付；我们负责海外独享 Mac、远程环境与 AI 工作流落地。

一站式服务怎么落地

先由余老师核清 ID 注册、账号、订阅和支付的各项成本，我们再确定整套服务售价，最后约定分销比例。当前先明确分工和服务内容，成本、整套售价与分销比例待确认。

值得花时间跟进的客户，要能答上三个问题：每周都在做同一件事吗？能给一份真实样本吗？谁决定花这笔钱？

第一类 · 渠道合作

AI 培训大V、账号与充值服务商

联系 AI 培训大V怎么说

“我们在美国加州提供独享 Mac mini 远程工作环境，帮你安全、稳定地用好 Claude Code，把 AI 生产力真正落到日常工作里。想约 30 分钟，用你自己的一个真实任务演示一遍，跑通一套能重复使用的工作流。你觉得有用，再推荐给学员。”

联系账号与充值服务商怎么说

“你已经在服务购买 ChatGPT、Claude 账号、订阅充值或 VPN 服务的付费客户。里面有没有客户还需要独享电脑、使用环境配置，或者想把 Claude Code 真正用到工作里？你继续做好现有服务，我们配合美国独享 Mac mini、远程环境和任务演示。先一起跑通一位客户，再用专属链接持续合作，Mac 租赁按首单计佣。”

从哪里找

  • 做 AI、编程、效率工具课程的大V和训练营负责人
  • 提供 ChatGPT、Claude 账号开通、订阅充值或 VPN 服务，且已有付费客户的个人与团队
  • 有付费学员、知识星球或活跃社群的老师
  • 做过企业内训、服务出海企业或海外华人学员的团队

先问什么

  • 现有付费客户主要是个人、学生家长，还是企业团队？
  • 他们更需要账号与订阅、独享机器、环境配置，还是具体任务的工作流？
  • 能否先约一位有明确需求的客户看演示，谁负责介绍和跟进？

合作怎么说

“你负责把真实需求带过来，我们配合环境配置、任务演示和交付。推广伙伴用专属链接带客户，按首单计佣：年付 15%、半年付 10%、季付 7.5%、月付 5%，续费不计。一个原价年付客户佣金 $258.57，十个为 $2,585.70。经销商的合作方式和价格单独沟通。”

下一步怎么推进

约好 30 分钟演示：培训伙伴先用老师自己的任务验证，账号与充值服务商先带一位有明确需求的付费客户参与。认可后再生成专属分销链接，发一页伙伴说明，并陪伙伴完成第一位客户的演示和交付。先明确现有客户需要什么，再推荐对应服务。

第二类 · 团队采购

想出海的中小企业

开场怎么说

“你们团队现在最想交给 AI 的，是产品开发、资料整理，还是出海销售和运营？我们提供美国加州的独享 Mac mini 远程环境，帮团队安全、稳定地用好 Claude Code。先用一个真实任务验证效果，再讨论怎么接进现有流程、如何分工，以及需要配几台。”

从哪里找

  • 大V和训练营的企业学员、企业内训客户
  • 账号与充值服务商已有的企业付费客户
  • 出海服务商、跨境电商社群和海外团队
  • 有重复任务、明确负责人和采购决策人的中小企业

先问什么

  • 哪项工作每周反复做，目前由谁做、怎么交付？
  • 能否提供一份真实样本，什么结果才算可用？
  • 多少人使用，涉及哪些资料和访问权限，谁决定预算，准备什么时候开始？

价值和报价怎么说

“我们先用真实任务验证 Claude Code 能否融入现有工作，确认操作流程、交付结果和团队使用方式。Mac 租赁月付 $169，单台年付基准价 $1,723.80，折合每月 $143.65。年付按同一账户同时在租台数享批量折扣：4–10 台 95 折、11–25 台 93 折、26–50 台 9 折、51–100 台 85 折；100 台以上单独报价。账号、订阅或额外服务按实际需求另行确认。”

下一步怎么推进

拿到样本和负责人，完成一次演示；再列清使用人数、机器台数、付款周期和交付内容，形成团队报价。先让首个任务交付可用结果，再讨论扩大配置。

第三类 · 配套服务

一站式客户与学生家长

开场怎么说

“如果您想用好 Claude Code，又希望账号、订阅、机器和使用环境都有人协助对接，我们可以按需求提供组合服务。账号和订阅交给合作伙伴，我们负责美国独享 Mac mini、远程环境和工作流落地，帮您更省心地开始使用。先聊清您想完成的任务，再确定配置和整套报价。”

面向家长：别把孩子的 AI 起跑线，留到“以后再说”

“您一直在为孩子的教育投入，AI 工具的使用能力，也值得从现在开始准备。会提问题、会判断结果、会借助先进工具把想法做成作品，都需要一次次动手积累。一直等‘以后有时间’，推迟的也是孩子本可以开始探索和练习的时间。”

“先给孩子一个接触先进工具、认真动手的机会。我们可以安排一次家长参与的小项目演示，用 Claude Code 展示如何把一个想法拆成步骤、编写、修改和验证。让您亲眼看到过程，再决定为孩子配置怎样的学习环境。”

让家长具体看到什么

  • 从孩子感兴趣的小网页、互动故事或编程小项目中选一个，按当前基础安排演示。
  • 展示如何提出需求、检查 AI 的回答、修改并验证结果。
  • 请孩子讲清自己的想法、做出的选择和下一步想改什么；让家长看到参与过程和作品。

家长说“再考虑考虑”时

“可以，先把您最在意的问题说清楚：孩子有没有兴趣、家长怎么参与、整套费用是多少。今天先约一次 30 分钟演示，把这些问题一起看明白。孩子愿意动手、您也认可这种方式，我们就确定第一个项目和配置，让这件事有一个真正开始的时间。”

从哪里找、先问什么

  • 优先覆盖北京、上海、广州、深圳、武汉等重点城市的学生家长
  • 通过 AI 或编程课程老师、账号与充值服务商、大V学员及已有客户介绍触达
  • 先问学习或工作目标、现有设备、希望谁来使用，以及需要哪些配套服务

分工和价格怎么说

账号注册、充值和订阅相关问题，统一交给合作伙伴（余老师）对接处理；我们负责美国独享 Mac mini、远程环境和 AI 工作流。先由余老师核清各项成本，再确定整套服务售价，最后约定分销比例。当前不把 Mac 租赁单价当作整套价格。

演示之后，怎么推进下单

“如果这个方向适合孩子，我们今天就把第一个项目、家长参与方式、配置清单和开始时间定下来。Mac 租赁可按月付 $169 开始；账号、订阅及配套服务单独列明费用。整套报价和交付内容确认后，再安排下单开通，让孩子的第一次实践有个明确起点。”

跟进时给出清晰的服务清单、整套报价和交付时间，确认家长的主要顾虑，并约定下一次沟通时间。

09什么时候停下来改

  • 招到的伙伴一周内没发链接：先查说明和案例，不要再加人。
  • 通过电话、微信、私信累计联系 50 次还没签下 1 个伙伴：换名单或换开场白。
  • 出现投诉或平台限制：停掉相应的联系方式。

10不能做的事

  • 不收入门费，不按拉人头发奖励，只按客户首单的真实付款计提成。
  • 不承诺收入。发分销内容前，先查各平台规则。
  • 不群发，不换号，不买私人通讯录。对方拒绝就停止联系。
  • 不转卖、代持或共享 Claude 账号。账号归客户所有，注册、订阅与使用遵守平台规则。
  • 不承诺固定的效率倍数，用真实案例说话。
  • 客户案例要先拿到授权。没签约不叫合作伙伴。
