# wodeMac 营销方案

原始 HTML 的 GitHub Pages 静态发布版本，保留营销方案和目标调整功能；已移除算账页面。

- 来源：用户提供的 `wodeMac 营销方案.html`（2026-11-05 版）
- 发布：GitHub Pages，`main` 分支根目录
- 无需构建或安装依赖
- GitHub Pages 不连接 Claude 数据库；目标修改通过浏览器 localStorage 保存在各自设备
- 页面中的价格、目标和财务假设均来自原文件，发布不代表重新核验

更新 `index.html` 并推送后，GitHub Pages 会自动重新发布。

## 页面与素材维护

- `index.html`：营销方案、章节导航及 10 / 20 / 50 / 100 / 200 / 500 台目标切换。
- `styles.css`：方案与素材中心共享样式，包含手机排版及打印样式。
- `materials.html`：宣传素材中心，按六个主题分类筛选。
- `materials.json`：素材清单。已上架 28 张完整场景海报，另保留一张学生家长参考截图，共 29 项。新素材插在列表最前，并加 `"new": true` 显示“最新”标记；上新时把上一批的 `new` 去掉。
- `materials.js`：分类筛选及图片、下载状态展示。

后续上传海报到仓库（建议放入 `assets/materials/`），将清单对应条目的 `image` 改为图片相对路径即可上架。`download` 可选，留空时下载原图。建议海报比例为 iPhone 竖版 1170 × 2532；网页按此比例展示，下载保留生成原图的原生像素。

### 生成与验证

无需安装依赖，使用 Python 3.9 或以上版本：

```sh
python3 scripts/update_seo.py
python3 scripts/validate_seo.py
```

公开问答与 JSON-LD 来自 `scripts/update_seo.py` 的同一份 `FAQ` 数据，修改后重新生成，避免可见正文和标记不一致。新资料页的正文也在该脚本维护。原有页面的 SEO head、新导航、首页服务事实区及素材生成区由脚本管理，其他原文不改。素材以 `materials.json` 为源，引用资源必须是仓库内真实文件；统一展示比例不表示所有原图拥有相同像素尺寸。

如规范域名协议确需调整，可传入已核验的地址重新生成：

```sh
python3 scripts/update_seo.py --base-url https://wodemac.vilesaint.com
```

验证包含 head 唯一性、可见 FAQ 与 JSON-LD 一致性、29 张静态卡片、站内链接与资源存在、索引策略和 XML 地图。搜索平台的域名验证文件由发布负责人维护，不加入 sitemap 或正文导航。

上线、证书、搜索平台提交、抓取、收录、排名和 AI 引用均须分别核实；本地检查通过不代表其中任一步骤已完成。
